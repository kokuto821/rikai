## REMOVED Requirements

### Requirement: ファイルに保存してもチャットにレポートを出す
**Reason**: ファイルを直接読めば内容が分かるので、保存中のチャットへのレポートの出力は二重になり、邪魔になる。
**Migration**: 新しい要件「ファイルに保存している間はチャットにレポートを出さない」に置き換える。

## MODIFIED Requirements

### Requirement: レポートの雛形
rikai は、理解度レポートを次の雛形に沿って出力しなければならない（SHALL）。（既定）`回答番号` には、レポートを出す時点で最後に数えた回答の番号を書く。回答番号を進めないターンでは、番号は前回のまま変わらない。出さなかった話題のレポートの番号は、古いままでよい。終了の応答の最終レポートには、直前に数えた回答の番号を書く（終了の応答は番号に数えないため）。通番の定義は rikai-question-selection に従う。（確定）

````markdown
# 理解度レポート: <話題>
回答番号: N
概要: <任意>

## 理解した箇所
- ...

## 一部理解した箇所
- ... （不足: ...）

## 理解できてない箇所
- ...

## AIから解説されたがユーザーからの返答がない箇所
- ...
````

#### Scenario: 雛形に沿った出力
- **WHEN** rikai が理解度レポートを出力する
- **THEN** 話題名、回答番号、概要（任意）、4つの項目の順で、雛形に沿って出力する

#### Scenario: 話題が複数あるときの回答番号
- **WHEN** 話題が複数に分かれているときにレポートを出力する
- **THEN** 出力するレポートには、出力時点で最後に数えた回答の番号を書き、出力しなかった話題のレポートの番号は変えない

#### Scenario: 回答番号を進めないターンのレポート
- **WHEN** 回答番号を進めないターンで、レポートを出力する
- **THEN** 回答番号は前回のレポートと同じ番号のままで、前回の問いへの「返答なし」の記録だけが反映される

## ADDED Requirements

### Requirement: ファイルに保存している間はチャットにレポートを出さない
ファイルへ保存している間、rikai は、理解度レポートも保存先の案内も、チャットに出してはならない（SHALL NOT）。レポートはファイルに書き込み、内容はファイルで確認できるようにする。判定結果と問いは、これまでどおり出す。（確定）出力順は rikai-session-mode に従う。

書き込みに失敗したときだけ、そのターンのレポートをチャットに出し、失敗した旨を1行で伝えなければならない（SHALL）。この1行は、付随の通知として、回答本文の直前に置く。終了の応答は別の扱いとする（下の段落）。前回のレポートは、会話の中で直近に書き込んだ内容（失敗したときは、チャットに出した内容）を前提にし、分からなければファイルを読み直す。（既定）

「保存先の案内」は、保存先のパスや、保存したことを知らせる通知を指す。初回保存時の、`.rikai/` を git で追跡するか除外するかを知らせる1行は、保存先の案内ではなく、付随の通知であり、この規則の対象外とする。（確定）

終了の応答では、最終の判定をファイルに反映してから、全話題の最終レポートの代わりに、保存したレポートのファイルのパスを、全話題ぶん1行に並べなければならない（SHALL）。反映に失敗したときは、最終レポートをチャットに出す。（確定）

保存に切り替えたターンから、この規則を適用する。切り替えより前の全話題の内容は、現在のレポートとしてファイルに書き出す。（既定）

#### Scenario: ファイル保存中の通常のターン
- **WHEN** ファイルへの保存を選んだ状態で、レポートを更新する
- **THEN** ファイルを更新し、レポートも保存先の案内もチャットには出さない。判定結果と問いは出す

#### Scenario: ファイルへの書き込みに失敗した
- **WHEN** ファイルへの保存を選んだ状態で、書き込みに失敗する
- **THEN** そのターンだけ、レポートをチャットに出し、失敗した旨を1行で伝える

#### Scenario: ファイル保存中の終了の応答
- **WHEN** ファイルへの保存を選んだ状態で、ユーザーが終了を命じる
- **THEN** 最終の判定をファイルに反映し、最終レポートの代わりに、保存したレポートのファイルのパスを、全話題ぶん1行に並べる

#### Scenario: 保存に切り替えたターン
- **WHEN** チャット内表示で進めていて、ユーザーがファイルへの保存を選ぶ
- **THEN** それまでの全話題の内容を現在のレポートとしてファイルに書き出し、そのターンから、レポートをチャットに出さない

# rikai-understanding-judgement Specification

## Purpose
ユーザーが回答を理解できているかを、AIの解釈との一致で判定し、理解度レポートの分類と採点・正解の提示の根拠にする。
## Requirements
### Requirement: ユーザーの返答とAIの解釈の一致で判定する
rikai は、ユーザーの返答がAIの解釈と一致しているかで、理解を判定しなければならない（SHALL）。判定の根拠は、ユーザーの仮説、オウム返しの内容、クイズの回答の3つとする。（確定）

3つの区別は次のとおり。（既定）

- 仮説: 問いとは無関係に、ユーザーが自発的に述べた解釈
- オウム返し: 質問提案で促された言い換え
- クイズの回答: クイズへの答え

#### Scenario: 自発的に述べた解釈
- **WHEN** ユーザーが問いとは無関係に、自発的に解釈を述べる
- **THEN** 仮説として扱い、AIの解釈との一致で判定する

#### Scenario: 促された言い換え
- **WHEN** ユーザーが質問提案で促された言い換えを返す
- **THEN** オウム返しとして扱い、AIの解釈との一致で判定する

#### Scenario: クイズへの答え
- **WHEN** ユーザーがクイズに答える
- **THEN** クイズの回答として扱い、AIの解釈との一致で判定する

### Requirement: 判定結果を4つに分類する
rikai は、判定結果を次の4つに分類しなければならない（SHALL）。（既定）

- 一致 → 理解した
- 部分一致 → 一部理解した（選択式で選択は合っているが理由が違う、など）
- 不一致、または詳細を詰める型の質問（何？／どこ？／仕組み？／なぜ？／具体的には？）で尋ねた → 理解できてない
- 返答なし → AIから解説されたがユーザーからの返答がない箇所

#### Scenario: 一致
- **WHEN** ユーザーの返答がAIの解釈と一致する
- **THEN** 「理解した」と判定する

#### Scenario: 部分一致
- **WHEN** ユーザーの返答がAIの解釈と一部だけ一致する（例: 選択式で、選択は合っているが理由が違う）
- **THEN** 「一部理解した」と判定する

#### Scenario: 不一致
- **WHEN** ユーザーの返答がAIの解釈と一致しない
- **THEN** 「理解できてない」と判定する

#### Scenario: 詳細を尋ねる質問
- **WHEN** ユーザーが「○○は何？」「○○ってどこ？」「どういう仕組み？」「なぜ○○？」「具体的には？」のいずれかで尋ねる
- **THEN** 「理解できてない」と判定する

#### Scenario: 返答なし
- **WHEN** AIが解説したが、ユーザーから返答がない
- **THEN** 「AIから解説されたがユーザーからの返答がない箇所」と判定する

### Requirement: 問いを無視した場合は返答なしとして記録する
ユーザーの発言に前回の問いへの返答（クイズの回答、提案された質問、言い換え）が含まれず、前回の問いが残っていた場合、rikai は「返答なし」として記録しなければならない（SHALL）。話題が同じでも別でも、記録は変わらない。（確定）

記録は黙って行い、ユーザーには通知しない。レポートの変化で気づかせる。（既定）記録先は、前回の問いの出題元の話題のレポートとする。ユーザーの発言が別の話題への仮説を含んでいても、返答なしは出題元の話題に記録し、仮説の判定は、仮説の対象の話題に記録する。（確定）

#### Scenario: 問いを無視して別の話題に移る
- **WHEN** ユーザーが前回の問いに答えず、別の話題に移る
- **THEN** 前回の問いの出題元の話題のレポートに「返答なし」として記録する

#### Scenario: 同じ話題で問いに答えず別の依頼をする
- **WHEN** ユーザーが前回の問いに答えず、同じ話題で別の依頼をする
- **THEN** 前回の問いの出題元の話題のレポートに「返答なし」として記録する

#### Scenario: 問いに答えず別の話題への仮説を述べる
- **WHEN** 話題Aの問いが残っている状態で、ユーザーが前回の問いに答えず、話題Bについての仮説を述べる
- **THEN** 話題Aのレポートに「返答なし」を記録し、話題Bの仮説の判定は話題Bのレポートに記録する

### Requirement: 判定は回答の正しさを保証しない
rikai の判定は、「AIの解釈との一致」を示すものでなければならない（SHALL）。AIの回答自体が正しいことの保証ではない。（既定）

#### Scenario: 一致した場合の意味
- **WHEN** ユーザーの返答がAIの解釈と一致し、「理解した」と判定する
- **THEN** AIの解釈との一致を示すだけで、AIの回答が正しいことは保証しない

### Requirement: コピペを理解として扱わない
rikai は、AIの回答文章全体をそのままコピペした返答を、理解したとは扱ってはならない（SHALL NOT）。AIの回答にある用語を使っていても、それだけではコピペ扱いしてはならない（SHALL NOT）。（確定）

#### Scenario: 用語を使った返答
- **WHEN** ユーザーの返答にAIの回答にある用語が含まれる
- **THEN** それだけではコピペ扱いしない

#### Scenario: 回答全体のコピペ
- **WHEN** ユーザーの返答がAIの回答の文章全体をそのままコピペしたものである
- **THEN** 理解したとは扱わない

### Requirement: 判定は返答の対象の話題のレポートに記録する
rikai は、判定結果を、返答が対象とする話題のレポートに記録しなければならない（SHALL）。（確定）前回の問いへの返答は、問いの出題元の話題のレポートに、問いとは無関係な仮説や詳細を尋ねる質問は、その対象の話題のレポートに記録する。

#### Scenario: 前回の問いへの返答の記録先
- **WHEN** ユーザーが前回の問いに答える
- **THEN** 問いの出題元の話題のレポートに判定結果を記録する

#### Scenario: 別の話題への仮説の記録先
- **WHEN** ユーザーが問いとは無関係に、別の話題についての仮説を述べる
- **THEN** その話題のレポートに判定結果を記録する
